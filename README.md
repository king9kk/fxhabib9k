# ⛽ Base Gas Tracker

Real-time gas price tracker for the Base blockchain network.

## Features
- ⚡ Live gas prices (Slow, Average, Fast)
- 📊 Gas price history chart
- 🧮 Fee calculator for common actions
- 🔔 Custom gas price alerts
- 🌐 Multi-network comparison
- 💡 Gas saving tips
- ⏱️ Auto-refresh with countdown
- 📱 Fully responsive design

## Gas Price Levels
| Level | Speed | Use Case |
|-------|-------|----------|
| 🐢 Slow | ~2 min | Non-urgent transfers |
| 🚗 Average | ~30 sec | Standard transactions |
| 🚀 Fast | ~10 sec | Time-sensitive actions |

## Network Info
- **Network:** Base Mainnet
- **Chain ID:** 8453
- **Explorer:** https://basescan.org

## Getting Started
1. Clone the repo
```bash
git clone https://github.com/king9kk/base-gas-tracker.git
```
2. Open `index.html` in browser
3. Gas prices update every 15 seconds

## Tech Stack
- HTML5, CSS3, JavaScript
- BaseScan API
- CoinGecko API
